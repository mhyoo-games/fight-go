# 파이트 고!

옥상에서 여럿이 뒤엉켜 싸우는 3D 난투 액션 웹 게임. 무대와 동작은 전부 코드로 만들었어요.

**하기: https://mhyoo-games.github.io/fight-go/**

## 지금 되는 것

- 컴퓨터 3명과 모두가 서로 싸우는 난투 (180초, 마지막까지 남으면 승리). 싸우면 ●(돈)을 벌어요.
- **유형 4가지** — 능력치 다섯(STR 힘 · TEC 조준 거리 · SPD 빠르기 · JMP 점프 · DEF 맷집)과 필살기가 달라요.
  주먹꾼(고루, 게이지가 빨리 참) · 요원(빠름, 두 번 점프) · 염력사(강공격이 멀리 가는 염력탄) · 장사(느리지만 세고 튼튼)
- **상점과 장신구** — 번 ●으로 장신구를 사서 하나를 끼면 Z+X · Z+C 기술과 능력치가 바뀌어요.
  권투 장갑 · 불꽃 팔찌 · 늑대 발톱 · 번개 장화 · 얼음 지팡이 · 바람 날개 (유형에 따라 조금씩 달라요)
- **달리기와 대시 공격** — 같은 방향을 두 번 누르면 달리고, 달리면서 X · C · X+C가 따로 있어요.
- **띄우기 콤보** — C나 올려치기로 띄운 상대는 공중에서 이어 때릴 수 있어요(다섯 번까지, 갈수록 약해짐). 누운 상대는 못 때리고, 일어날 때 잠깐 무적.
- **막기** — X+C를 같이 누르고 있으면 앞에서 오는 공격을 막아요. 뒤에서 맞거나 너무 많이 막으면 뚫려요.
- **낙법과 기상 공격** — 날아가다 땅에 닿기 직전 V를 누르면 바로 일어나고, 누운 채 X나 C를 누르면 일어나며 둘레를 차요.
- **줍는 무기** — 방망이(Z+C 멀리 날리기) · 소총 · 바주카(터지면 둘레가 다 맞고, 공중에서 X를 누르면 로켓을 타고 날아요). 쓸수록 닳고, 맞아서 날아가면 떨어뜨려요. 도시락을 주우면 체력이 차요.
- **넓은 옥상 마을** — 높이가 다른 옥상 넷, 계단, 널빤지 다리, 상자, 그리고 문으로 들어가는 창고. 밖으로 떨어지면 체력이 크게 줄어요.

## 조작

| 키 | 하는 일 |
|---|---|
| 방향키 | 걷기 (같은 방향 두 번 = 달리기) |
| Z | 조준 (조준 거리 안의 가장 가까운 상대를 봄) |
| X | 약공격 (X X X 연타) · 무기 옆에서는 줍기 |
| C | 강공격 (띄우기) · 무기 옆에서는 줍기 |
| V | 점프 |
| X+C (같이 누르고 있기) | 막기 (앞에서 오는 공격만. 많이 막으면 깨져요) |
| Z+X · Z+C | 장신구 기술 (맨손이면 조준 치기, 무기를 들면 무기 기술·던지기) |
| Z+X+C | 필살기 (게이지 절반) |
| 달리며 X · C | 대시 공격 (미끄러져 차기 · 무릎 띄우기) |
| 달리며 X+C | 대시 필살기 (게이지 1/4) |
| 공중 X · C | 공중 공격 |
| 공중 X+C | 점프 필살기 |
| 날아가다 땅에 닿기 직전 V | 낙법 |
| 누운 채 X · C | 기상 공격 |
| 문 앞에서 ↑ | 문으로 들어가기 |

## 만든 방법

- Godot 4.6 (GDScript, GL Compatibility) → 웹으로 내보내 GitHub Pages에.
- 규칙(이동·기술 표·맞는 판정·날아가기·무대 발판·컴퓨터)은 `scripts/rules.gd`에 화면과 떨어뜨려 두고 `tests/run_tests.gd`로 확인.
- 캐릭터는 Kenney Animated Characters Protagonists(CC0) 모델. 동작은 팩의 것을 쓰지 않고 `scripts/fighter.gd`가 뼈를 직접 움직여 만든다(기술마다 준비 → 치기 → 돌아오기, 걷기·달리기는 계산). 장신구·무기·무대(`scripts/stage.gd`)는 코드.
- 효과음·곡은 코드로 합성한 것(`tools/sound/gen.py`). 글꼴: 갈무리 (SIL OFL).
