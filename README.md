# 파이트 고!

옥상에서 여럿이 뒤엉켜 싸우는 3D 난투 액션 웹 게임. 캐릭터와 무대는 전부 코드로 만들었어요.

**하기: https://mhyoo-games.github.io/fight-go/**

## 지금 되는 것 (첫 버전)

- 컴퓨터 3명과 모두가 서로 싸우는 난투 (120초, 마지막까지 남으면 승리)
- **유형 4가지** — 주먹꾼(고루, 게이지가 빨리 참) · 요원(빠름, 두 번 점프) · 염력사(강공격이 멀리 가는 염력탄) · 장사(느리지만 세고 튼튼)
- **장신구 3가지** — 맨손 · 권투 장갑 · 방망이. Z+X, Z+C 기술이 바뀌고, 유형에 따라 조금씩 달라요 (염력사는 염력탄이 덤, 장사는 더 넓게)
- 옥상 무대: 높이가 다른 옥상 셋, 계단, 옥탑방 위. 밖으로 떨어지면 체력이 크게 줄어요

## 조작

| 키 | 하는 일 |
|---|---|
| 방향키 | 이동 |
| Z | 조준 (가장 가까운 상대를 봄) |
| X | 약공격 (X X X 연타) |
| C | 강공격 (띄우기) |
| V | 점프 |
| Z+X · Z+C | 장신구 기술 (맨손이면 조준 치기) |
| Z+X+C | 필살기 (게이지 절반) |
| 공중 X · C | 공중 공격 |
| 공중 X+C | 점프 필살기 |

## 만든 방법

- Godot 4.6 (GDScript, GL Compatibility) → 웹으로 내보내 GitHub Pages에.
- 규칙(이동·기술 표·맞는 판정·날아가기·무대 발판·컴퓨터)은 `scripts/rules.gd`에 화면과 떨어뜨려 두고 `tests/run_tests.gd`로 확인.
- 캐릭터(`scripts/fighter.gd`)는 공·캡슐·상자를 관절로 이어 만들고 자세를 각도로 준다. 무대(`scripts/stage.gd`)도 코드.
- 효과음·곡은 코드로 합성한 것(`tools/sound/gen.py`). 글꼴: 갈무리 (SIL OFL).
